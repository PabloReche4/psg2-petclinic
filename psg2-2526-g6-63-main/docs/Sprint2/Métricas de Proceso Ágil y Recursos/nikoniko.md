# Calendario Niko-Niko del equipo G6-63
En este documento se encuentra el calendario Niko-Niko, que sirve para controlar la moral del equipo y poder actuar en consecuencia para mejorarla lo máximo posible.

### Sprint 2 - Guía de uso

| Día           | Miembro A  |
| ------------- | ------------- |
| Día 1         |    😁 (Significa que estoy aprendiendo, me gusta el trabajo y creo que puedo hacerlo sin problemas, aunque con algo de esfuerzo) |
| Día 2         |     - (Significa que no hice trabajo relacionado con el proyecto PSG2)           |
| Día 3         |    😑  (Significa que sentí que tuve que esforzarme, pero el trabajo asignado fue justo y el día productivo)          |
| Día 4         |    😟(Significa que siento serias dificultades para completar la tarea, o que la productividad de mi día fue muy mala)           |
| Día 5         |    😫 (Estoy desesperado, necesito ayuda)        |
